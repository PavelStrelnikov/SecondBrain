# Second Brain

Личный ассистент-перехватчик. Архитектура: docs/architecture.md. Язык общения и документации: русский. Код и комментарии в коде: русские комментарии допустимы, идентификаторы английские.

## Правила

- Отдельный проект. Никакого кода из ServiceCRM не копировать; связь с CRM только по сети через её MCP.
- Таблица событий неизменяема: только INSERT. Всё производное перестраивается из неё.
- Каждая запись наружу и каждое событие с телефона несут ключ идемпотентности.
- Модели вызываются только из модуля extract; остальной код детерминирован.
- Личные данные живут в отдельной базе brain_personal, не в brain_work.

## Как проверять

- Ядро: `cd core && pytest -q` (юнит-тесты без базы); с базой задать TEST_DATABASE_URL.
- Приложение: собирается только в GitHub Actions (workflow android); локального Android SDK в облачной среде нет.
