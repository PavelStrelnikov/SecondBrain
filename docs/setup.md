# Запуск с нуля: ядро, туннель, телефон

Пошагово, для первой установки. Ничего из ServiceCRM не трогаем, это отдельный проект со своими портами.

## Что понадобится

- Компьютер, где уже работает Docker (тот же, где крутится CRM).
- Аккаунт Cloudflare, в котором уже есть туннель для CRM.
- Телефон Samsung Galaxy с Android 14 или новее.

## Шаг 1. Скачать проект на компьютер

Открой терминал (PowerShell на Windows, Terminal на Mac) и выполни по одной строке:

```bash
cd ~
git clone https://github.com/PavelStrelnikov/SecondBrain
cd SecondBrain
```

Появится папка `SecondBrain` рядом с `ServiceCRM`, не внутри неё.

## Шаг 2. Создать файл настроек

```bash
cp .env.example .env
```

На Windows в PowerShell: `copy .env.example .env`.

Открой `.env` в любом редакторе и заполни:

| Строка | Что вписать |
| --- | --- |
| `POSTGRES_PASSWORD` | Любой пароль для базы, например 20 случайных букв и цифр |
| `DATABASE_URL` | Тот же пароль вместо `change_me` в середине строки |
| `DEVICE_TOKEN` | Длинная случайная строка. В терминале: `openssl rand -hex 32`, скопируй результат. На Windows без openssl подойдёт любая строка из 40+ случайных символов |
| `HEALTH_PASSWORD` | Пароль для страницы «здоровье» в браузере |
| `CLOUDFLARE_TUNNEL_TOKEN` | Пока оставь пустым, заполним на шаге 4 |

Файл `.env` не попадает в git, пароли остаются только у тебя.

## Шаг 3. Запустить ядро

```bash
docker compose up -d --build
```

Первый запуск качает образы, 1–3 минуты. Проверка:

```bash
docker compose ps
```

Должны быть два контейнера в состоянии `running`: `brain-db` и `brain-core`. Затем открой в браузере `http://localhost:8400`. Браузер спросит логин и пароль: логин `brain`, пароль из `HEALTH_PASSWORD`. Увидишь страницу «Second Brain · здоровье» с надписью «Событий ещё нет». Это нормально.

Если что-то не так, посмотри логи:

```bash
docker compose logs core --tail 50
```

## Шаг 4. Открыть ядро наружу через Cloudflare

Телефон должен достучаться до ядра из любого места, поэтому нужен публичный https-адрес. Используем Cloudflare Tunnel, как у CRM, но отдельный туннель, чтобы не трогать настройки CRM.

1. Зайди на https://one.dash.cloudflare.com, слева **Networks → Tunnels**.
2. **Create a tunnel → Cloudflared**, имя `brain`, далее.
3. На экране «Install connector» выбери Docker. В команде будет длинный `--token eyJ...`. Скопируй только сам токен (всё после `--token`).
4. Вставь его в `.env` в строку `CLOUDFLARE_TUNNEL_TOKEN=`.
5. Нажми «Next». На вкладке «Public Hostname»: Subdomain `brain`, Domain твой домен, Type `HTTP`, URL `core:8400`. Сохрани.
6. В терминале:

```bash
docker compose --profile tunnel up -d
```

Через минуту в Cloudflare туннель станет `Healthy`. Проверка с телефона в браузере: открой `https://brain.твой-домен/api/health`. Должно ответить `{"status":"ok","last_event_age_s":null}`.

Важно: в поле URL написано `core:8400`, не `localhost`. Туннель живёт в том же Docker-окружении и видит ядро по имени контейнера.

## Шаг 5. Установить приложение на телефон

1. На телефоне открой https://github.com/PavelStrelnikov/SecondBrain/releases/tag/latest и скачай файл `secondbrain-capture-N.apk`.
2. Открой скачанный файл. Телефон скажет, что установка из этого источника запрещена, и предложит разрешить. Разреши для браузера и установи.
3. Открой приложение **Second Brain**.

## Шаг 6. Настроить приложение

1. **Адрес сервера**: `https://brain.твой-домен` (с `https://`, без слэша в конце).
2. **Токен устройства**: строка из `DEVICE_TOKEN` в `.env`. Удобно переслать себе в «Избранное» и скопировать.
3. Нажми **Сохранить и проверить связь**. Ожидаемый ответ: «связь есть, токен принят». Если «токен неверный», сверь строку. Если «нет связи», проверь шаг 4.
4. Кнопка **1. Звонки и уведомления приложения**: разреши всё, что спросит.
5. Кнопка **2. Доступ к уведомлениям WhatsApp**: откроется системный список, найди Second Brain и включи. Телефон предупредит, что приложение сможет читать уведомления. Это и есть цель.
6. Кнопка **3. Не усыплять приложение**: разреши.
7. В разделе «Разрешения» все три строки должны стать с галочками ✓.

## Шаг 7. Отключить экономию батареи Samsung

One UI убивает фоновые службы, если этого не сделать. Два места:

1. **Настройки → Батарея → Ограничения в фоновом режиме** (в некоторых версиях «Обслуживание устройства → Батарея → Ограничения в фоновом режиме»):
   - **Спящие приложения**: убедись, что Second Brain там нет, если есть, удали из списка.
   - **Приложения без ограничений**: добавь Second Brain.
   - Выключи **Перевод неиспользуемых приложений в спящий режим**, иначе через несколько дней оно уснёт само.
2. **Настройки → Приложения → Second Brain → Батарея**: выбери «Без ограничений».

## Шаг 8. Проверить, что всё летит

1. Позвони себе с другого телефона или попроси кого-нибудь позвонить и сбросить.
2. Попроси прислать сообщение в WhatsApp.
3. Открой `https://brain.твой-домен` в браузере (логин `brain`, пароль из `HEALTH_PASSWORD`).

В разделе «Источники» должны появиться строки `android / call`, `whatsapp / message` и `android / app_state` с давностью в секундах или минутах. В «Последних 50» видны сами события: номер и длительность звонка, отправитель и текст сообщения.

Если события не появляются: в приложении нажми **Отправить сейчас** и посмотри строку «ошибка» в разделе «Состояние». Её текст скажи мне.

## Что дальше

Живи с телефоном как обычно неделю. Раз в день заглядывай на страницу «здоровье»: строка `app_state` должна быть не старше 30 минут. Если она красная и старше часов, значит Samsung усыпил службу, и мне нужно знать, когда это случилось.

Обновления приложения: новая сборка появляется в Releases под тем же тегом `latest`. Скачай и установи поверх, данные и настройки сохранятся.
